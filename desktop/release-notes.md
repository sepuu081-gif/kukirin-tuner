Download **KuKirin-Tuner-Setup-1.0.74.exe** and open it. No ZIP extraction is needed. It installs for your Windows user and creates the game shortcut.

The game checks GitHub for updates after opening and periodically while it is running. Updates download in the background and install when you close the game normally. You can also use **Uuendused → Paigalda ja taaskäivita** after finishing your ride. Windows shutdown skips installation until the next normal game close.

Existing account, garage and career saves stay in the same Windows user profile. Older ZIP releases need this EXE installed once to get the updater. APK was not built.

The additional latest.yml and blockmap files are updater metadata; players only need the EXE. Every future release must increase package.json version and publish its complete updater files together.
